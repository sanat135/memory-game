# Memory Game — Спелая память

Игра на поиск восьми пар карточек с реалистичными изображениями овощей и фруктов. Чистые HTML, CSS и JavaScript, без библиотек для интерфейса и игровой логики.

## Локальный запуск

Требуется Node.js 18 или новее. Из папки проекта выполните:

```sh
node server.cjs
```

Откройте http://localhost:4173. Установка зависимостей не нужна. Для остановки сервера нажмите Ctrl+C.

## Как играть

Открывайте две карточки за ход и запоминайте их расположение. Совпавшая пара остаётся открытой, несовпавшая закрывается через секунду. Найдите все восемь пар за минимальное число ходов. Кнопка «Новая игра» перемешивает поле и обнуляет счётчики. «Таблица лидеров» показывает 10 лучших завершённых игр, сохранённых в браузере.

## Структура

- `index.html` — подключение приложения; body содержит только script.
- `src/app.js` — интерфейс, карточки и взаимодействие с игровым состоянием.
- `src/game.js` — перемешивание, выбор карточек, счётчики и отмена таймера.
- `src/modal.js` — общий компонент модального окна.
- `src/storage.js` — проверка, сортировка и сохранение результатов.
- `src/styles.css` — адаптивное оформление и анимации.
- `assets/produce.png` — локальный атлас из восьми изображений, созданный встроенным imagegen; CSS отображает нужный участок на каждой карточке. Сторонние фотостоки и внешние шрифты не используются.
- `assets/leaf.svg` — собственная иконка вкладки.
- `tests/` — тесты игровой логики и рейтинга.

## Проверки

```sh
node --test
```

Карточки доступны с клавиатуры (Tab, Enter или пробел). Модальные окна закрываются кнопкой, Escape или нажатием на фон. Анимации учитывают настройку reduced motion. Если браузер запрещает localStorage, игра работает, но показывает сообщение о невозможности сохранить рейтинг.
